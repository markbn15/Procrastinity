# Procrastinity
Procrastinity es una app nativa de Android desarrollada en Kotlin para la gestión del tiempo y la creación de hábitos. Combina gamificación con mascotas virtuales (Árbol, Pez, Rana) y fricción cognitiva (retardo de 15s) para reducir el uso impulsivo de redes sociales, todo bajo un enfoque 100% offline y local.
